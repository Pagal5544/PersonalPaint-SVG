Export

SVG ZIP में हर फ्रेम अलग vector file होगा। WebM export सभी SVG फ्रेम को जोड़कर silent video बनाएगा। MP4 conversion इस browser-only build में शामिल नहीं है; WebM को किसी editor में MP4 में बदल सकते हैं। लंबे वीडियो या अधिक FPS के लिए ज्यादा RAM और समय लगेगा।

नोट: यह raster वीडियो को vector paths में trace करता है, इसलिए pixel-perfect original नहीं होगा। फोटो/जटिल scenes में SVG फाइल बड़ी हो सकती है। Processing पूरी तरह इसी browser में होती है; कोई Gemini API या server आवश्यक नहीं।
